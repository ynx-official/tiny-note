# Tiny Note tiny-note-v0.1.12

> 发布日期：2026-08-27

## 版本概述

本版本修复笔记页首次打开时数据未及时加载的问题，并优化在线更新弹窗的阅读体验。更新说明支持 Markdown 渲染，内容较多时可在弹窗内滚动查看，同时收敛弹窗尺寸，保持操作区域始终可见。

## 改进与修复

- 修复首次进入笔记页时笔记列表为空、切换 tab 后才恢复的问题。
- 笔记页启动时主动加载笔记、模板和标签数据，避免依赖其他页面间接初始化。
- 在线更新说明支持标题、列表、引用、粗体、链接、代码块和表格等 Markdown 格式。
- 限制在线更新弹窗最大高度，更新内容过多时仅内容区域上下滚动。
- 增加在线更新 Markdown 渲染回归测试。

## 兼容性

- 本版本不改变笔记、知识库、任务或图片生成数据格式。
- 现有设置和本地工作区可以继续使用。

## 验证说明

- 本地已通过更新弹窗测试、类型检查、Lint 和样式检查。
- 推送版本 tag 后由 GitHub Actions 执行发布校验和跨平台打包。

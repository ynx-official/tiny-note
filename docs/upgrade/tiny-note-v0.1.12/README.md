# Tiny Note tiny-note-v0.1.12

> 发布日期：2026-08-28

## 版本概述

本版本完善外部 Markdown 工作流和笔记阅读体验，并优化模型选择、启动交互和正式发布流程。外部文件可以更自然地纳入工作区管理，文章会恢复上次阅读位置；发布流水线改为并行构建、统一上传，Release 只保留实际安装包。

## 新增与改进

- 支持外部 Markdown 文件和文件夹管理。
- 外部 Markdown 默认进入即时编辑模式，并记忆每篇文章的相对阅读位置。
- 增加侧栏工具提示和更清晰的无障碍标签。
- 对话模型菜单过滤不支持图片生成的模型。
- 优化 Windows Tauri 开发服务连接和应用启动过渡。
- 正式发布改为四平台并行构建，统一发布任务只上传 `.exe`、`.dmg`、`.AppImage` 和 `.deb` 安装包。

## 兼容性

- 现有笔记、外部 Markdown 绑定、设置和本地工作区格式保持兼容。
- 本版本不改变图片生成和任务数据结构。

## 验证说明

- 按发布约定，本地发布前跳过测试；发布后的 GitHub Actions 负责版本校验、基础 CI 和跨平台安装包构建。

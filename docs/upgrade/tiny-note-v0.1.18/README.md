# Tiny Note tiny-note-v0.1.18

> 发布日期：2026-09-21

## 版本概述

本版本优化笔记工作区和编辑器的布局与交互，补充全部笔记列表和共享图片支持，并改进聊天导航状态保持与托盘样式。

## 新增与改进

- 优化笔记工作区布局、编辑器工具栏、侧栏和全部笔记列表。
- 改进编辑器多模式体验，支持共享图片内容处理。
- 保持聊天导航状态，改善会话关闭后的恢复行为。
- 对齐托盘面板的视觉样式和交互反馈。

## 兼容性

- 本版本不改变既有笔记、知识库、任务或图片生成数据格式。
- 现有设置和本地工作区可以继续使用。

## 验证说明

- 按发布请求跳过本地测试、Lint、类型检查和构建验证。
- 推送版本 tag 后由 GitHub Actions 执行发布校验和跨平台打包。

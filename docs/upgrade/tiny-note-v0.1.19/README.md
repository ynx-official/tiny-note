# Tiny Note tiny-note-v0.1.19

> 发布日期：2026-09-29

## 版本概述

本版本新增同步设置和手动同步能力，改进远端正文刷新、目录更新、账号切换隔离及自动保存状态反馈，并完善关于页版本说明展示。

## 新增与改进

- 新增“同步”设置，支持自动更新开关、秒/分钟检查间隔和“立即同步”。
- 改进窗口恢复、网络恢复和周期检查时的远端正文与目录刷新。
- 保留未保存草稿、Markdown 解析中间态、阅读位置和有效选区，避免后台刷新覆盖编辑内容。
- 增加等待保存、保存中、已保存和保存失败重试状态。
- 关于页升级说明改为读取完整版本详情，支持 Markdown 展示。

## 兼容性

- 本版本不改变既有笔记、知识库、任务或图片生成数据格式。
- 同步偏好仅保存在当前设备；关闭自动更新不会关闭自动保存，手动同步仍可使用。

## 验证说明

- 按发布请求跳过本地测试、Lint、类型检查和构建验证。
- 推送版本 tag 后由 GitHub Actions 执行发布校验和跨平台打包。

# Tiny Note tiny-note-v0.1.17

> 发布日期：2026-09-18

## 版本概述

本版本新增 Markdown 笔记本文件夹导入和图片交互式预览，并改进图片生成、后台任务、聊天会话连续性及生产构建配置说明。

## 新增与改进

- 支持导入 Markdown 笔记本文件夹。
- 新增图片交互式预览，改善图片生成工作流和历史结果查看体验。
- 改进后台任务进度、重试状态和错误反馈。
- 保持聊天会话在工作区导航之间连续。
- 补充生产构建配置、交互连续性和 Markdown 导入架构文档。

## 兼容性

- 本版本不改变既有笔记、知识库、任务或图片生成数据格式。
- 现有设置和本地工作区可以继续使用。

## 验证说明

- 按发布请求跳过本地测试、Lint、类型检查和构建验证。
- 推送版本 tag 后由 GitHub Actions 执行发布校验和跨平台打包。

# Tiny Note tiny-note-v0.1.13

> 发布日期：2026-09-04

## 版本概述

本版本完成业务后端向 Go 服务的迁移，统一生产环境默认配置和远程 API 契约，并恢复 Agent 工具、动态 MCP 能力与只读系统技能。同时增强登录会话、后台任务、消息持久化、头像展示、笔记自动保存和远程冲突处理的可靠性。

## 新增与改进

- 迁移 Tiny Note 业务请求到 GoFrame 后端，统一生产环境 API 默认地址和前端远程命令契约。
- 恢复 Agent 工具和动态 MCP 运行时能力，并增加只读系统技能目录。
- 持久化 Agent 请求消息 ID，记录 Agent 失败状态，改善长对话和失败恢复体验。
- 增强登录会话恢复与用户头像展示。
- 增加服务端权威后台任务和登录流程支持。
- 串行化笔记自动保存，保留远程冲突与会话状态，提升同步可靠性。

## 兼容性

- 本版本继续使用现有笔记、知识库、任务和图片生成数据格式。
- 需要使用可访问的 Tiny Note Go 业务后端；生产环境默认地址已更新为 `https://go.mrsunshine.cn/prod-api`。

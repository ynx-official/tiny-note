# Tiny Note tiny-note-v0.1.10

> 发布日期：2026-08-25

## 版本概述

本版本新增完整的 AI 图片创作工作区，并升级笔记编辑、图表渲染和文档导出体验。用户可以直接使用统一模型配置完成文字生图、参考图生图、图片编辑和局部重绘，也可以将历史生成结果继续用于后续创作。文章输出拆分为独立打印、PDF、HTML 和 Markdown 导出，并统一基于最新已同步、再次清洗的文章快照，避免桌面外壳、编辑器临时状态或 Mermaid 瞬时 SVG 进入结果。

## 新增功能

- 新增文字生图、参考图生图、整图编辑和局部重绘四种图片创作模式。
- 模型设置支持标记可用生图模型，并设置首选生图模型。
- 支持上传参考图、复用历史生成结果和绘制局部重绘蒙版。
- 支持提示词智能优化、撤销优化及后台生图任务。
- 生图历史使用紧凑缩略图展示，点击可在窗口内查看大图并下载。
- 笔记编辑器新增 Mermaid 图表编辑、预览和错误提示。
- 新增独立“导出 PDF”入口，直接生成 A4 PDF 文件。
- 新增独立“导出 HTML”入口，输出 UTF-8 文档、内联阅读样式和当前界面语言。
- 保留系统“打印”入口，并为打印生成独立文章版式。

## 改进与修复

- 笔记工作区迁移到 Friday 风格的桌面布局、尺寸和交互状态。
- 优化图片创作页面在不同窗口宽度下的控件排列、任务状态和历史卡片密度。
- 提示词优化保留用户原始描述，降低优化结果偏离核心意图的概率。
- 点击任一输出操作前先同步 150ms 防抖窗口内的最新 Markdown 草稿。
- 文件名保留中文与 Emoji，同时处理系统保留名、非法字符和 UTF-8 长度上限。
- PDF 对标题与首个内容块、代码块、表格、任务列表、图表和图片提供分页保护；长文在浏览器画布安全范围内动态调整倍率，超过范围时提示改用打印或拆分文章。
- 远程图片通过匿名 CORS 图片加载路径安全嵌入，不扩大应用 `connect-src`；失败、超时或超出资源预算时显示带说明和来源主机的占位内容。
- 打印只显示文章正文，重置应用窗口的最小宽度与滚动限制，并补齐 macOS Tauri 打印权限。
- 新增导出进度、重复操作保护、中英文提示，以及更多菜单的方向键、Escape、外点关闭和焦点恢复。
- 修复 Windows 下发布资料校验脚本把 `file://` URL 解析成重复盘符的问题，并让关于页回退版本直接读取构建元数据。

## 兼容性

- 图片生成记录和本地附件继续保存在 Tiny Note 工作区内，已有数据会自动迁移。
- 现有笔记、知识库、外部 Markdown 绑定和备份格式保持兼容。
- 图片编辑能力要求所选 OpenAI 兼容服务支持图片生成与 `/images/edits` 接口。
- PDF 当前使用栅格化渲染，优先保证视觉版式；文字通常不可搜索或选择，文件体积也可能高于文本型 PDF。
- HTML 中保留的远程链接与图片在打开时仍可能访问对应站点。

## 验证结果

- 前端单元测试、ESLint 和 Vite 生产构建通过。
- Rust 格式检查、单元测试和 Clippy 通过。
- Windows Tauri NSIS 安装包构建通过。
- 已抽样检查中文、Emoji、表格、任务列表、代码块、Mermaid 源码、图片和六页长文 PDF，并在生产 CSP 下验证 CORS 远程图片嵌入。
- 正式标签会触发 GitHub Actions 构建 Windows、Linux、Intel macOS 和 Apple Silicon macOS 安装包，并生成在线更新清单。

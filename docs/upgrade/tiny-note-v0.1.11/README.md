# Tiny Note tiny-note-v0.1.11

> 发布日期：2026-08-27

## 版本概述

本版本聚焦启动体验、助手抽屉和前端命令契约质量。应用启动时展示更稳定的静态加载外壳与首页加载状态，工作区在笔记、设置、待办和助手抽屉之间保持更一致的布局与交互；同时补充 Tauri 命令请求和事件通道的明确类型，降低前后端契约漂移风险。

## 改进与修复

- 优化静态启动外壳和首页初始化期间的加载反馈。
- 优化助手抽屉、头像抽屉、笔记、设置和待办工作区的布局与样式状态。
- 为图片生成、后台任务、Agent、AI 流式请求和导出写文件补充明确的命令类型。
- 改善任务结果、图片生成结果和浏览器预览任务的类型处理。
- 增加头像抽屉和首页加载状态的回归覆盖。
- 修正组件大小检查脚本的边界处理。
- 外部 Markdown 默认使用即时编辑；每篇文章在当前设备独立记住相对阅读位置，重新打开后自动恢复，文章模式仍只有即时编辑和 Markdown 两种。

## 兼容性

- 本版本不改变笔记、知识库、任务或图片生成数据格式。
- 现有设置和本地工作区可以继续使用。

## 验证说明

- 按发布请求，本地发布前跳过测试执行；推送后由 GitHub Actions 执行发布校验和跨平台打包。

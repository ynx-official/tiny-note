# Tiny Note tiny-note-v0.1.20

> 发布日期：2026-09-30

## 版本概述

本版本将笔记编辑器统一迁移到 Vditor，改进即时编辑、Markdown 模式、工具栏和主题体验，并支持粘贴图片上传；同时简化笔记工作区结构，补充编辑器架构与交互资料。

## 新增与改进

- 统一使用 Vditor 编辑器，支持即时编辑 IR 与 Markdown SV 模式切换。
- 改进编辑器工具栏、主题、代码块、Mermaid 图表和 AI 选区处理。
- 支持在笔记编辑器中粘贴图片并上传。
- 独立展示笔记名称、保存状态和文档操作，优化笔记工作区布局。
- 编辑器资源改为本地打包，并补充 Vditor 架构和验证说明。

## 兼容性

- 本版本继续使用现有笔记和工作区数据格式。
- 现有设置和本地工作区可以继续使用。

## 验证说明

- 按发布请求跳过本地测试、Lint、类型检查和构建验证。
- 推送版本 tag 后由 GitHub Actions 执行发布校验和跨平台打包。

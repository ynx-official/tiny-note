# Tiny Note tiny-note-v0.1.15

> 发布日期：2026-09-09

## 版本概述

本版本采用 Friday 桌面工作区外壳，统一主窗口的布局与交互体验；同时改进 Agent 回复持久化，并让托盘与主窗口共享认证会话状态。

## 新增与改进

- 采用 Friday 桌面工作区骨架，改善笔记、助手和工作区的整体使用体验。
- 改进 Agent 回复持久化和发布说明布局。
- 同步托盘与主窗口认证会话，减少不同入口之间的登录状态不一致。

## 兼容性

- 本版本不改变笔记、知识库、任务或图片生成数据格式。
- 现有设置和本地工作区可以继续使用。

# 威胁模型

状态：Review
最后更新：2026-08-21

- 所有文件命令只接受知识库 ID 与相对路径，拒绝越界路径和符号链接穿透。
- 原始 Markdown 与可执行预览分离保存。进入预览和 `content_html` 的内容仅允许编辑器所需标签、属性、`color/background-color/text-align` 样式及 HTTP(S)、邮件、电话和相对链接协议；脚本、事件属性、危险图片/Data URL、未知标签和其他样式被移除。
- 模型 Key 只进入本地 SQLite 和 Rust HTTP 请求；错误、日志和前端 DTO 均脱敏。SQLite 数据库文件需要按本机敏感数据保护。
- WebView 不开放任意 Shell、任意目录读写或远程页面导航。
- 自动检索和明确引用都只接受笔记 ID 或知识库 ID + 相对路径。发送给模型的文件片段被标记为不可信数据，文件中的提示词不得覆盖系统指令。
- 某模型首次接收本地内容前需要用户授权；拒绝后可以普通聊天，但不发送笔记和知识库上下文。界面展示本轮实际使用的来源和截断状态。
- AI 不能直接写知识库文件。笔记写入必须来自仍为 `draft` 的提案，通过更新时间和正文哈希校验，并在写入前创建本地版本快照。
- Agent 只可调用 Rust 注册表中的工具，未知工具和非法参数必须拒绝。只读工具可以自动运行；任何新增的笔记、记忆、文件或外部写操作都必须先进入持久化审批，并将批准绑定到不可替换的工具参数。
- Agent 每轮限制工具循环次数和输出大小；工具结果作为不可信数据返回模型，不得覆盖系统指令。第一阶段不开放任意 Shell、Python、包安装或知识库写入。
- Skill 名称只允许字母、数字、连字符和下划线；Rust 拒绝路径穿越与符号链接。模型读取 Skill 无需审批，通过工具写入 Skill 必须审批；内置 Skill 不允许删除。
- MCP 服务由用户显式配置并以独立进程启动，命令与参数不经过 Shell。工具清单需先连接发现，模型每次实际调用外部 MCP 工具都必须通过参数绑定审批；响应按不可信数据处理并限制长度。
- 子 Agent 不继承任何工具，只接收主 Agent 显式提供的任务上下文，并在执行前提示额外模型用量。脚本执行使用无文件、网络和进程 API 的 Rhai 引擎，限制操作次数、递归深度、集合与字符串大小，不提供任意 Shell 或 Python。

# 威胁模型

状态：Review
最后更新：2026-08-25

- 所有文件命令只接受知识库 ID 与相对路径，拒绝越界路径和符号链接穿透。
- 文章导出不授予前端通用文件系统写权限。原生文件夹选择器只允许用户选择目录；Rust 导出命令重新校验目录存在且为文件夹、文件名只能是单个普通路径组件、解码后内容不超过 64 MiB，并用排他创建避免覆盖已有文件。默认导出目录只保存在本机设置和工作区备份中。
- 导出后的“打开文件/定位文件”不向前端授予 Opener 的任意路径 capability。Rust 仅登记当前进程中确实由导出命令创建的规范化路径，后续操作必须命中最多 256 条的会话授权集合；其他本机路径一律拒绝。
- 原始 Markdown 与可执行预览分离保存。进入预览和 `content_html` 的内容仅允许编辑器所需标签、属性、`color/background-color/text-align` 样式及 HTTP(S)、邮件、电话和相对链接协议；脚本、事件属性、危险图片/Data URL、未知标签和其他样式被移除。
- 打印、HTML 和 PDF 共用从 `content_html` 生成的文章快照，并在输出前再次执行同一白名单清洗；标题单独转义。导出不序列化当前 WebView DOM，因此桌面外壳、AI 临时状态和事件处理器不进入文件；HTML/PDF 仅从已清洗快照内的 Mermaid 围栏源码调用严格渲染器，嵌入经二次清洗的 SVG，渲染失败则保留源码。HTML 中保留的 HTTP(S) 链接和图片仍可能在用户打开文件时访问对应远程地址；PDF 不放宽 `connect-src`，而是通过现有 `img-src https:` 允许的匿名、无 Referrer CORS 图片元素加载并在受限画布中转为 Data URL。远图按顺序处理，受 3 秒单图、9 秒总时长、24 张、单图 12 MiB 转换产物、总计 24 MiB、4096 像素边长和 800 万像素画布预算约束；不安全、超时或超限时生成可见占位提示。
- Mermaid 源码按不可信输入处理。进入 Mermaid 解析/渲染前先拒绝图片节点、Markdown 图片、外部 URL、CSS `url()`/`@import` 和资源标签，防止生成 SVG 之前发生网络请求；渲染器使用 `securityLevel: strict`、关闭用户 HTML 标签与自动启动、锁定安全/主题/布局配置，并限制文本和边数量。返回 SVG 继续移除脚本、事件属性、链接、图片、外部 URL 和危险 CSS；只保留 Mermaid 生成的内部主题 `<style>` 及指向同一 SVG 定义的 `url(#fragment)`，避免节点和分组回落为浏览器默认黑色。仅为 Mermaid 原生泳道标题保留经二次清洗的 `foreignObject` 及 `div/span/p/br` 最小 XHTML 白名单。该白名单只存在于图表专用渲染器，不加入通用编辑器 HTML 白名单；SVG 只存在于瞬时 NodeView，禁止写入数据库。
- HTML 图表交互运行时由应用内 Mermaid 预览共用视口内核序列化而来，仅使用固定原生 JavaScript，不加载外部依赖，不执行 Mermaid 源码或图内文本，不发起网络请求；用户内容只进入经二次清洗的 SVG 节点。PDF 渲染阶段不注入该运行时或交互控件。
- 模型 Key 只进入本地 SQLite 和 Rust HTTP 请求；错误、日志和前端 DTO 均脱敏。端点类型使用固定白名单，Rust 按协议选择 Bearer 或 `x-api-key`，不把凭据拼入 URL。SQLite 数据库文件需要按本机敏感数据保护。
- WebView 不开放任意 Shell、任意目录读写或远程页面导航。
- 自动检索和明确引用都只接受笔记 ID 或知识库 ID + 相对路径。发送给模型的文件片段被标记为不可信数据，文件中的提示词不得覆盖系统指令。
- 某模型首次接收本地内容前需要用户授权；拒绝后可以普通聊天，但不发送笔记和知识库上下文。界面展示本轮实际使用的来源和截断状态。
- AI 只能通过注册工具在受管知识库内创建或移动 Tiny Note 自有的 `.note` 引用，不能任意改写其他知识库文件。移动前按引用内的精确笔记 ID 匹配，拒绝越界目录、符号链接和多重歧义；失败时回滚笔记或移动。知识库元数据仍只能通过注册的创建、更新、删除工具修改。笔记修改必须来自仍为 `draft` 的提案，笔记删除只设置最近删除时间。
- Agent 只可调用 Rust 注册表中的工具，未知工具和非法参数必须拒绝。系统为各工具提供保守的默认审批值；用户可通过正式“工具与权限”入口单个或批量覆盖。Rust 在每次执行前读取 SQLite 生效策略；需要审批时仍将批准绑定到不可替换的工具参数，设置为无需审批时仍记录完整工具审计。
- Agent 每轮限制工具循环次数和输出大小；工具结果作为不可信数据返回模型，不得覆盖系统指令。第一阶段不开放任意 Shell、Python、包安装或知识库文件写入。
- Skill 名称只允许字母、数字、连字符和下划线；Rust 拒绝路径穿越与符号链接。模型读取 Skill 默认无需审批，通过工具写入 Skill 默认需要审批，二者都服从用户审批策略；内置 Skill 不允许删除。
- MCP 服务由用户显式配置并以独立进程启动，命令与参数不经过 Shell。工具清单需先连接发现，实际调用遵循用户为 `call_mcp_tool` 设置的审批策略；响应始终按不可信数据处理并限制长度。
- 子 Agent 不继承任何工具，只接收主 Agent 显式提供的任务上下文，并在执行前提示额外模型用量。脚本执行使用无文件、网络和进程 API 的 Rhai 引擎，限制操作次数、递归深度、集合与字符串大小，不提供任意 Shell 或 Python。
- 后台任务入库前递归拒绝 API Key、Token、Password 和 Secret 字段；模型凭据仍只在 Rust 内按模型配置 ID 读取。任务状态使用白名单转换，终态不能被旧事件重新激活。
- 应用重启不自动恢复可能包含写操作的任务，避免重复创建、修改或删除；手动重试创建可审计的新尝试。同一资源串行执行，降低上下文乱序和提案覆盖风险。

# 架构概览

状态：Review（当前实现基线，稳定性验收进行中）。最后更新：2026-09-09。

## 服务端业务边界

Vue 3、TypeScript、Pinia 和 Vue Router 负责客户端页面、编辑器和状态投影。业务数据由 tiny-blog-go 的 GoFrame 模块提供，通过 REST 读写、SSE 推送。MySQL 是笔记、会话、提案及任务结果的权威存储，Redis 提供会话和跨实例事件分发，私有 S3 对象存储承载附件与图片。

`src/services/commandMap.ts` 保持已有命令的类型契约；`tauri.ts` 将平台命令交给 Tauri，业务命令经 `remoteCommands.ts` 路由到 `apiClient.ts`。`browserBackend` 只用于测试，浏览器生产模式也访问服务端。命令归类检查不是实际 HTTP 接口或端到端验收的替代品。

## 桌面与外部文件

Rust 仅负责窗口、托盘、通知、更新、系统凭据及授权文件能力，不执行笔记业务 CRUD、模型调用、Agent 或后台业务任务。不读取、迁移或删除旧 SQLite 目录。

从系统打开的 Markdown 只建立本机路径授权和独立文件历史，前端将文件内容转换为编辑器视图。外部文档使用 `external:` 标识，不调用云端笔记创建或更新接口。保存时由 Rust 核对源路径与编辑会话指纹，然后在同目录写临时文件并原子替换，保留 UTF-8 BOM、源权限和 Markdown 换行。外部修改、源文件丢失或路径替换会拒绝保存；用户重新打开后读取磁盘内容。

外部文档不参与普通笔记列表、标签、双向链接、Agent 引用或服务端备份。清空历史不删除源文件。“导入到笔记”创建独立云端副本，之后的副本编辑不写回源文件。云端 AI 修改需先导入。历史版本已经创建的云端副本不自动删除，存量核对仍列为稳定性待办。

## 目录与正文

笔记树、回收站、标签和引用选择器使用 `note_page` 的独立摘要分页；树计数来自服务端聚合，搜索覆盖完整正文。摘要与可编辑的 `Note` 分开存储，编辑和图片追加前按 ID 读取完整正文，保存入口拒绝摘要对象。

正文缓存按 20 篇 / 64 MiB 的软预算回收，保留当前笔记、未解析源码及未保存修改；编辑器保存签名采用弱引用。切换先保存，读取失败保留当前编辑器，过时响应不得改变新选择或越过账号重置边界。容量不是整个 WebView/RSS 的硬上限，真实桌面千篇/万篇性能仍须验收。

## 登录

托盘收集箱是独立 WebView，不能直接读取主窗口模块内存。主窗口通过仅面向 `tray-panel` 的 Tauri 事件同步内存会话；托盘先完成会话握手，再读取待办。此修复不要求勾选“保持登录”，不增加凭据持久化，也不修改服务端认证规则。登录和退出同步更新已打开的托盘；托盘的 401 只使主窗口中相同令牌的会话失效；登录状态改变后丢弃旧 JSON 请求响应，避免旧数据重新进入托盘。参见[威胁模型](threat-model.md)。

业务页面需要登录。令牌运行时保存在内存；保持登录只使用操作系统安全凭据库，不回退到 localStorage。401 清理会话并引导重新登录。界面须明确业务内容存储在当前账号的云端空间。

## AI 与后台任务

总结、笔记 AI、图片和内部标题使用类型化任务入口，由服务端冻结输入、执行模型、持久化状态与结果。客户端只订阅事件并回查权威结果，不能创建通用任务或自行迁移状态。普通对话及 Agent 在对话内呈现；Agent 审批和结构化输入仍在原会话恢复。

笔记 AI 先产生提案，应用时服务端校验归属和提案原始版本，并在一个事务中保留修订、更新正文、消费提案。变更后的笔记不得被旧提案覆盖。普通对话、笔记 AI 和 Agent 不自动扩展检索引用之外的内容。

## 页面与输出

保留 Friday 桌面外壳、三栏结构、标签栏和尺寸变量。首页同步挂载，其余路由、编辑器、Mermaid 和 PDF 导出按需加载；主题和外壳样式与异步页面样式隔离。生产 SFC、路由样式、命令归类和启动资源预算受脚本检查。

HTML/PDF 导出在前端从安全正文快照生成；落盘通过授权导出命令，避让同名文件。系统打印由 WebView 转发。主窗口启动可用、实际安装和升级仍须分别验证。

## 验收依据

实施进展和未完成项见[迁移修复与稳定性](../06-delivery/stabilization.md)。服务端使用显式 migrations 命令管理数据库，HTTP 启动不执行 DDL。真实集成测试须运行隔离 MySQL/Redis/MinIO 和两个业务实例，不以模拟后端单测或集成套件仅编译代替。

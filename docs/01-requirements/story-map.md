# 故事地图（Approved）

## MVP

- 启动应用 → 查看全部笔记 → 新建/编辑/自动保存 → 搜索、删除、恢复。
- 管理笔记本 → 创建、重命名、删除（笔记移到未分类）。
- 管理笔记元数据 → 标签、置顶、模板、`[[笔记标题]]` 关联笔记。
- 查看知识库 → 创建个人/本地库 → 新建文件夹、导入文本/二进制/网页 URL、重命名、删除到回收站 → 递归搜索和预览。
- 设置主题、语言和模型元数据；API Key 仅由 Rust 写入本地 SQLite。
- 编辑器 AI 操作以 Channel 事件流传输，支持取消；FIM 默认关闭。
- 设置页导出/恢复完整工作区（模型 API Key 不进入备份）；Tiny Agent 作为带审批的实验能力提供。

## 当前范围外

日程、自动化、账号、云同步、分享、跨设备协作、Friday 数据迁移、全文索引、自动 RAG 和知识库问答。Agent 保留受控的笔记、笔记本与知识库元数据工具，但不自动读取本地内容。

## 模式与会话规则

右侧编辑器工具栏在“添加到知识库”后显示当前文章模式，下拉顺序固定为：即时编辑、Markdown。首次打开编辑器使用即时编辑；同一编辑器会话切换文章时保持当前模式、Markdown 预览开关和分栏比例，应用重启后不持久化。

默认使用 `Ctrl+/` 在 Windows/Linux 上、`⌘+/` 在 macOS 上于即时编辑和 Markdown 之间双向切换。快捷键在正文或 CodeMirror 获得焦点时同样生效；设置页提供独立“快捷键”分类，并按“编辑器”等功能分组，用户可录入新的组合键或恢复默认值。自定义快捷键按当前设备持久化，不写入笔记、工作区或云端；修改后旧组合键不再负责模式切换。

- 即时编辑：TipTap 提供 Notion 式所见即所得编辑，显示格式工具栏、Bubble Menu 和启用后的 FIM；标题下拉固定显示“标题、标题 1、标题 2、标题 3、正文、小正”，并用对应字号预览层级。输入标题、列表、引用和代码块等 Markdown 快捷语法后立即呈现对应格式。粘贴 Markdown 立即渲染，并短暂显示“已按 Markdown 渲染 / 查看源码”入口。
- Markdown：CodeMirror 6 编辑处理后的 Markdown，具备行号、高亮、搜索、自动换行和随主题变化的颜色。格式工具栏保留撤销、重做、链接、粗体、斜体、删除线、行内代码、标题、列表和引用，并直接修改当前源码选区；标题下拉沿用即时编辑的六项顺序，其中“小正”使用可安全往返的 `p[data-small-text]` 混合 HTML。实时预览默认打开，可在工具栏关闭；打开时使用同一 TipTap 实例只读预览，宽度不足 720px 时改为上下布局，拖拽比例限制为 30%–70%，两栏按滚动百分比双向联动。

编辑器不再提供与正文分离的标题输入框。首个非空内容行按 Friday 规则显示为文档标题并同步到 `notes.title`，派生元数据最多保留 50 个字符；即时编辑把首个普通段落或 H1–H3 规范化为带 `data-note-title` 的专用 `noteTitle` 节点，标题末尾回车进入或创建普通正文段落，正文标题菜单与清除格式不得把该节点降级。Markdown 继续保留用户输入的原始标题级别和换行，切回即时编辑后再按上述标题节点显示。

## 流程图与泳道图

Markdown 围栏语言为 `mermaid` 时，即时编辑和 Markdown 实时预览都显示图形预览。插入菜单提供带 `accTitle`/`accDescr` 的流程图和泳道图起始模板；原生泳道图使用 `swimlane-beta`，顶层 `subgraph` 表示泳道。

图表块提供源码/预览切换、75%–250% 手动缩放和应用内大图预览；行内预览固定默认适合宽度，不显示重复的适宽按钮，仍可用数字 `0` 恢复自动适宽。大图预览提供 10%–250% 缩放、适合宽度、复制源码和“屏幕全屏”；屏幕全屏优先使用系统原生全屏，不支持时铺满应用窗口，Esc 先退出屏幕全屏、再次按下才关闭大图预览。“适合宽度”允许缩到手动下限以下作为全图概览，100% 始终表示 SVG 原始比例。放大后的滚动限制在图表舞台内，不得撑出文章或应用横向滚动；源码渲染失败时清除过期预览、保留完整源码，并提供重试与查看源码入口。主题变化时重新渲染，亮暗主题均使用项目文字、表面、边线和强调色。

Mermaid SVG 由围栏源码和主题派生，不写入 `content_html`、Markdown 或历史版本；HTML/PDF 导出时会从已保存的源码重新渲染并嵌入经二次清洗的 SVG，不序列化编辑器中的瞬时 DOM。应用内预览与导出 HTML 共用同一个无 Vue 依赖的视口内核，自然尺寸、自动适宽、缩放步进、滚轮节流、鼠标锚点和滚动边界算法仅保留一份。HTML 正文内的图表默认为静态适宽预览，只显示“放大查看”；点击后在具有焦点陷阱和 Esc 关闭的聚焦层中启用内核，工具栏只保留当前比例、适合宽度、全屏和关闭，不显示加、减或 100% 按钮。聚焦层保留 10%–250% 手动缩放、最低 1% 的自动适宽、15% 滚轮鼠标锚点缩放、鼠标左键拖动与键盘操作。聚焦层可进一步通过 Fullscreen API 占满整个屏幕；Esc 优先退出系统全屏，再次 Esc 才关闭聚焦层；PDF 为静态页面，只保留适合页宽的渲染成品。渲染采用严格安全级别、锁定配置、文本/边数上限和 SVG 二次清洗；为避免笔记内容在渲染阶段触发网络请求，图表图片节点与外部资源不予渲染，用户仍可保留并编辑原始源码。普通代码围栏仍按代码块展示。

## 内容同步

Markdown 是 Markdown 模式的唯一源格式，不提供 HTML 源码模式。源码编辑后 150ms 解析为安全 HTML 和纯文本并刷新实时预览，随后沿用 800ms 自动保存；切换模式、文章或卸载前只在内容变更时强制解析和保存。空白、空引用、空有序列表等编辑中间态必须通过宽容解析刷新预览，不能显示为源码解析失败，也不能阻断源码保存。

连续且同层级的普通引用行（例如多行 `> 文档状态` 元数据）在解析预览时按用户输入保留单换行；该转换只作用于派生预览，不直接改写 Markdown 草稿。引用中的列表、代码围栏、表格、标题和 HTML 块不应用该转换，引用外普通正文仍把单换行视为软换行。

普通结构使用 GFM；普通高亮和下划线使用 TipTap 扩展语法。颜色、彩色高亮、对齐、上下标和复杂表格以经过白名单清洗的 HTML 保真。Markdown 模式编辑期间保持用户原始换行和混合 HTML；切回即时编辑只负责渲染，下一次即时编辑产生实际正文修改后允许将 Markdown 规范化为语义等价写法。

旧笔记的 Markdown 为空时，首次进入 Markdown 模式从现有 HTML 延迟生成，但仅在用户实际编辑或保存内容后回填。Markdown 源码始终按用户原文保存；若严格预览解析无法处理编辑中间态，则降级为安全 HTML 预览。只有两级预览都失败时才保留最后有效 HTML，并显示“预览暂未更新，源码已保存”。开发期遗留的顶层 `data-note-title` 会作为首个标题块继续读取，错误写入表格单元格的同类节点修复为普通段落。

## 文章导出与打印

“更多”菜单分别提供导出 Markdown、导出 HTML、导出 PDF 和打印。四种操作必须在执行前立即同步当前 Markdown 草稿，因此用户无需等待 150ms 预览刷新；导出动作不改变当前编辑模式，也不要求先手动保存。

- Markdown 原样导出当前源码，其中首个非空内容行同时承担文章标题。
- HTML 生成带 UTF-8 声明、从首个非空内容行读取的标题、内嵌阅读样式和安全正文的完整文档；正文再次经过与预览相同的 HTML 白名单清洗，并移除已单独渲染的首个标题块以避免重复。
- PDF 使用与 HTML/打印相同的文章快照和 A4 阅读版式，直接生成 `.pdf` 文件，不再次打开系统打印对话框。
- 打印只把文章标题和去除重复标题块后的正文送入系统打印流程，不包含桌面外壳、侧栏、工具栏、标签输入、AI 面板或其他应用界面。

导出文件名从文章标题生成，并移除 Windows/macOS/Linux 文件系统不允许的字符，同时限制 UTF-8 字节长度；空标题或系统保留名回退为安全名称。PDF 根据文章长度自动降低到安全渲染倍率；超过浏览器画布安全范围时明确提示改用“打印”保存 PDF 或拆分文章，不生成已知为空白的文件。远程图片通过 CSP 已允许的匿名 CORS 图片加载路径尝试嵌入，不开放跨域脚本请求；处理设有单图、总量、数量、像素和时间预算，无法安全读取或超过预算时在原位置输出带图片说明和来源主机的占位提示，不静默丢失内容。HTML/PDF 会把持久化的 Mermaid 围栏源码重新渲染为安全的内联 SVG；HTML 另嵌入不依赖网络的固定交互脚本，打印 HTML 时自动隐藏控件并恢复适宽图形；单个图表渲染失败时在原位置显示警告并保留源码，其余文章继续导出。

Markdown、HTML 和 PDF 首次导出且尚未设置默认位置时，先显示位置确认，并通过系统文件夹选择器选择目录；用户可勾选“以后都保存到此目录”，勾选后将目录写入本机应用设置。设置页提供独立“文件保存位置”分类，可查看、更换或清除默认目录；清除后恢复为每次首次导出时选择。未勾选时目录只用于本次导出。已有同名文件不得被静默覆盖，使用递增后缀创建新文件。打印不使用文件保存位置。

桌面端文件实际写入成功后显示“导出成功”结果弹窗，提供“打开所在文件夹”“打开文件”“以后再说”三个操作。默认焦点落在“打开文件”，Escape 等同“以后再说”；打开或定位失败时保留弹窗并显示错误。浏览器预览沿用浏览器下载且不声称能够定位下载文件。

## AI 与现有能力

全文助理在两个模式均可用，发送前同步当前源码。AI 全文替换刷新 Markdown、HTML 和纯文本，并保持当前模式；Markdown 不提供可靠插入位置，因此禁用“应用插入”。Markdown 导出优先使用 `contentMarkdown`。

本期不接入 CodeMirror 选区 AI，也不在非即时编辑模式显示 TipTap Bubble Menu 或 FIM。

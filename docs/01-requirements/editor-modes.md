- 2026-09-30：根据用户反馈，修正已设定的笔记标题被正文首行覆盖的问题，替代 2026-08-26 的无条件标题同步规则。已有 `notes.title` 优先；打开笔记不触发改名或保存，正文编辑也不覆盖已有名称。未命名笔记仅在首次编辑会话中自动取名，重命名后或重新打开已命名笔记时不再跟随正文。导出使用保存的笔记标题，并保留与之不同的首个正文标题。

- 2026-08-26：根据产品确认，移除独立阅读模式，只保留“即时编辑、Markdown”两个主模式；新增默认 `Ctrl+/`（macOS 为 `⌘+/`）双向切换，并允许用户在设置中自定义快捷键。快捷键配置仅保存在当前设备，不随笔记或工作区同步。

## 模式与会话规则

2026-09-30 按用户预览反馈移除编辑区“笔记本路径 / 文章标题”行；笔记名称继续在顶部独立输入框显示，普通文章名称行下方直接为格式工具栏。

2026-09-30 样式修订：按用户反馈，两个模式的正文、格式工具栏、代码块和明暗主题优先使用 Vditor 原生样式；移除旧编辑器排版覆盖。验收要求旧笔记样式同时加载时，正文仍采用原生字号/行距，非聚焦代码块正常折叠源码，窄区分栏无横向溢出，保存与 AI 流程不受影响。

同日后续确认：按效果图方向采用 Vditor 专用应用主题，替代上段临时纯原生的视觉要求；具体字号、宽度、间距与配色以[设计系统](../02-design/design-system.md#2026-09-30-确认-vditor-应用主题)为准。继续验收原生标记折叠、Markdown 保真切换、窄栏无溢出及 AI/保存可用，主题切换不得修改正文。

`contentMarkdown` 是正文权威内容，`markdownSource` 不限制即时编辑。Vditor 即时渲染（IR）与源码（SV）共用同一个实例。打开文章、只切换模式不回写或规范化原始 Markdown；实际手动编辑采用 Vditor/Lute 的序列化规则，可能规范化空白和等价标记。Front matter、公式、脚注、双向链接和原始 HTML 不再因旧 TipTap 兼容检测而强制源码模式；未知扩展不承诺有专用可视化控件，可在源码模式编辑。

2026-09-30 修复：同一篇文章切换模式时先将当前源码提交到内存文档，再异步保存；模式切换不等待网络响应。保存失败保留名称和正文草稿，显示错误并允许通过保存状态重试，不得静默停留在原模式。切换文章、关闭前的保存规则不变。

右侧编辑器工具栏在独立名称行显示当前文章模式，下拉顺序固定为：即时编辑、Markdown。首次打开编辑器使用即时编辑；普通文章在同一编辑器会话切换时保持当前模式、Markdown 预览开关和分栏比例，应用重启后不持久化模式。外部 Markdown 每次打开均默认进入即时编辑，不继承此前文章的 Markdown 模式。

即时编辑正文和 Markdown 实时预览共用按文章 ID 保存的阅读位置。位置以可滚动距离的 `0–1` 比例保存在当前设备，不写入笔记正文或工作区备份；切换文章、切换模式和关闭编辑器前立即保存，重新打开文章后按当前正文高度恢复。无有效记录、短文章或异常存储值回到顶部。

默认使用 `Ctrl+/` 在 Windows/Linux 上、`⌘+/` 在 macOS 上于即时编辑和 Markdown 之间双向切换。快捷键在Vditor 正文或源码 获得焦点时同样生效；设置页提供独立“快捷键”分类，并按“编辑器”等功能分组，用户可录入新的组合键或恢复默认值。自定义快捷键按当前设备持久化，不写入笔记、工作区或云端；修改后旧组合键不再负责模式切换。

- 即时编辑：Vditor IR 输入 Markdown 后直接呈现格式，保留原生标题 H1–H6、粗体、斜体、删除线、列表、任务列表、引用、链接、图片、表格和代码工具，以及撤销/重做。
- Markdown：Vditor SV 编辑源码，使用同一套原生格式工具；预览默认开启，可关闭。两栏支持 30%–70% 拖动和比例滚动同步，编辑区小于 720px 改为上下布局。不再沿用 CodeMirror 的行号和独立搜索 UI。
- 两个模式都提供选区 AI、自定义指令、助理和启用后的 FIM。AI 建议在独立前后对照面板中审阅，确认后通过 `note_edit_apply` 原子保存；原文中不插入高亮/删除线审阅标记。选区使用 Markdown UTF-16 偏移和源文快照，重复文字按位置区分；源文或服务端版本变化时拒绝过期建议。
- 公式、代码高亮及 Mermaid 依赖随应用打包，不要求远程 CDN；Mermaid 使用项目已有版本与严格安全模式。PlantUML 保留源码，不向公共渲染服务上传内容。

编辑器顶部共用独立笔记名称输入框，第一行按“文档图标、名称、真实保存状态、模式、导出、目录、助理”排列，Markdown 模式增加预览开关；第二行仅展示适用的正文格式工具。名称直接更新 `notes.title`，沿用 800ms 自动保存及切换前刷新；正文编辑不参与命名，空名称回退为“未命名笔记”，输入框仍允许用户清空后继续输入，中文输入法组合期间不提交中间拼音。Enter 转入当前模式正文。外部 Markdown 的名称显示为只读，避免把笔记改名误当成磁盘文件重命名。

首段及 H1–H3 保持自身格式，不再自动提升为专用标题节点；旧的顶层 `data-note-title` 在显示时转为普通 H1，保留文字和格式，打开不会写回，实际编辑后再按既有 Markdown 序列化规则保存。正文标题采用 Vditor 原生 H1–H6，与独立笔记名称无绑定关系；目录收录所有正文标题。

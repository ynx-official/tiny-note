## 模式与会话规则

右侧编辑器工具栏在“添加到知识库”后显示当前文章模式，下拉顺序固定为：富文本、源码 + 预览、纯源码、阅读。首次打开以及切换到另一篇文章时均回到富文本；模式和 50% 的初始分栏比例不持久化。

- 富文本：TipTap 可编辑，显示格式工具栏、Bubble Menu 和启用后的 FIM。
- 源码 + 预览：CodeMirror 6 编辑 Markdown，同一 TipTap 实例只读预览。宽度不足 720px 时改为上下布局；拖拽比例限制为 30%–70%，两栏按滚动百分比双向联动。
- 纯源码：只显示 CodeMirror，具备行号、Markdown 高亮、搜索、自动换行和随主题变化的颜色。
- 阅读：标题和 TipTap 正文只读，隐藏格式工具；保留模式、知识库、更多、目录和全文助理。正文可选择复制，安全链接通过系统浏览器打开。

## 内容同步

Markdown 是源码模式的唯一源格式，不提供 HTML 源码模式。源码编辑后 150ms 解析为安全 HTML 和纯文本，随后沿用 800ms 自动保存；切换模式、文章或卸载前只在内容变更时强制解析和保存。

普通结构使用 GFM；普通高亮和下划线使用 TipTap 扩展语法。颜色、彩色高亮、对齐、上下标和复杂表格以经过白名单清洗的 HTML 保真。源码编辑保持用户原始换行和混合 HTML；下一次富文本实际编辑后允许规范化 Markdown。

旧笔记的 Markdown 为空时，首次进入源码模式从现有 HTML 延迟生成，但仅在用户实际编辑或保存内容后回填。解析失败时保留最后有效 HTML 与当前会话源码草稿，显示“源码解析失败，尚未保存”，不得覆盖数据库。

## AI 与现有能力

全文助理在四种模式均可用，发送前同步当前源码。AI 全文替换刷新 Markdown、HTML 和纯文本，并保持当前模式；源码、分栏和阅读模式不提供可靠插入位置，因此禁用“应用插入”。Markdown 导出优先使用原始 `contentMarkdown`。

本期不接入 CodeMirror 选区 AI，也不在非富文本模式显示 TipTap Bubble Menu 或 FIM。

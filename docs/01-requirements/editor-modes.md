## 模式与会话规则

右侧编辑器工具栏在“添加到知识库”后显示当前文章模式，下拉顺序固定为：即时编辑、Markdown、阅读。首次打开编辑器使用即时编辑；同一编辑器会话切换文章时保持当前模式、Markdown 预览开关和分栏比例，应用重启后不持久化。

- 即时编辑：TipTap 提供 Notion 式所见即所得编辑，显示格式工具栏、Bubble Menu 和启用后的 FIM；输入标题、列表、引用和代码块等 Markdown 快捷语法后立即呈现对应格式。粘贴 Markdown 立即渲染，并短暂显示“已按 Markdown 渲染 / 查看源码”入口。
- Markdown：CodeMirror 6 编辑处理后的 Markdown，具备行号、高亮、搜索、自动换行和随主题变化的颜色。实时预览默认打开，可在工具栏关闭；打开时使用同一 TipTap 实例只读预览，宽度不足 720px 时改为上下布局，拖拽比例限制为 30%–70%，两栏按滚动百分比双向联动。
- 阅读：标题和 TipTap 正文只读，隐藏格式工具；保留模式、知识库、更多、目录和全文助理。正文可选择复制，安全链接通过系统浏览器打开。

笔记标题是独立元数据，并在三个模式顶部使用同一标题输入区域；标题不自动写入 Markdown 正文，也不把正文第一个 H1 强制提升为标题。Markdown 导出保持正文源码，不静默添加标题 H1。

## 流程图与泳道图

Markdown 围栏语言为 `mermaid` 时，即时编辑、Markdown 实时预览和阅读模式都显示图形预览。插入菜单提供带 `accTitle`/`accDescr` 的流程图和泳道图起始模板；原生泳道图使用 `swimlane-beta`，顶层 `subgraph` 表示泳道。

图表块提供源码/预览切换、75%–250% 手动缩放、适合宽度、应用内全屏和复制源码；“适合宽度”允许缩到 75% 以下作为全图概览，100% 始终表示 SVG 原始比例。放大后的滚动限制在图表舞台内，不得撑出文章或应用横向滚动；源码渲染失败时清除过期预览、保留完整源码，并提供重试与查看源码入口。主题变化时重新渲染，亮暗主题均使用项目文字、表面、边线和强调色。

Mermaid SVG 只是由源码和主题派生的瞬时 DOM，不写入 `content_html`、Markdown、历史版本或导出文件。渲染采用严格安全级别、锁定配置、文本/边数上限和 SVG 二次清洗；为避免笔记内容在渲染阶段触发网络请求，图表图片节点与外部资源不予预览，用户仍可保留并编辑原始源码。普通代码围栏仍按代码块展示。

## 内容同步

Markdown 是 Markdown 模式的唯一源格式，不提供 HTML 源码模式。源码编辑后 150ms 解析为安全 HTML 和纯文本并刷新实时预览，随后沿用 800ms 自动保存；切换模式、文章或卸载前只在内容变更时强制解析和保存。空白、空引用、空有序列表等编辑中间态必须通过宽容解析刷新预览，不能显示为源码解析失败，也不能阻断源码保存。

普通结构使用 GFM；普通高亮和下划线使用 TipTap 扩展语法。颜色、彩色高亮、对齐、上下标和复杂表格以经过白名单清洗的 HTML 保真。Markdown 模式编辑期间保持用户原始换行和混合 HTML；切回即时编辑只负责渲染，下一次即时编辑产生实际正文修改后允许将 Markdown 规范化为语义等价写法。

旧笔记的 Markdown 为空时，首次进入 Markdown 模式从现有 HTML 延迟生成，但仅在用户实际编辑或保存内容后回填。Markdown 源码始终按用户原文保存；若严格预览解析无法处理编辑中间态，则降级为安全 HTML 预览。只有两级预览都失败时才保留最后有效 HTML，并显示“预览暂未更新，源码已保存”。开发期曾写入正文的 `data-note-title` 标题在加载时迁回独立标题区域，错误写入表格单元格的同类节点修复为普通段落。

## 文章导出与打印

“更多”菜单分别提供导出 Markdown、导出 HTML、导出 PDF 和打印。四种操作必须在执行前立即同步当前 Markdown 草稿，因此用户无需等待 150ms 预览刷新；导出动作不改变当前编辑模式，也不要求先手动保存。

- Markdown 继续只导出正文源码，不自动添加独立标题。
- HTML 生成带 UTF-8 声明、独立标题、内嵌阅读样式和安全正文的完整文档；正文再次经过与预览相同的 HTML 白名单清洗。
- PDF 使用与 HTML/打印相同的文章快照和 A4 阅读版式，直接生成 `.pdf` 文件，不再次打开系统打印对话框。
- 打印只把独立标题和正文送入系统打印流程，不包含桌面外壳、侧栏、工具栏、标签输入、AI 面板或其他应用界面。

导出文件名从文章标题生成，并移除 Windows/macOS/Linux 文件系统不允许的字符；空标题或系统保留名回退为安全名称。Mermaid 继续只导出持久化的围栏源码，不把瞬时 SVG 写入 HTML、PDF 或打印快照。

## AI 与现有能力

全文助理在三个模式均可用，发送前同步当前源码。AI 全文替换刷新 Markdown、HTML 和纯文本，并保持当前模式；Markdown 和阅读模式不提供可靠插入位置，因此禁用“应用插入”。Markdown 导出优先使用 `contentMarkdown`。

本期不接入 CodeMirror 选区 AI，也不在非即时编辑模式显示 TipTap Bubble Menu 或 FIM。

# 业务规则（Approved）

最后更新：2026-08-24

- 笔记自动保存防抖 800ms，退出或切换前强制刷新。
- Markdown 源码编辑防抖 150ms 生成 HTML/纯文本并刷新预览，随后进入 800ms 保存。空文档、`1. `、`> ` 等正常编辑中间态使用宽容预览，不得阻断源码原文保存；若预览确实无法更新，保留最后有效 HTML 并明确提示“源码已保存”。同一编辑器会话切换文章时保持模式、预览开关和分栏比例，不因单纯查看更新时间。
- 即时编辑会把正文序列化为语义等价的规范化 Markdown；Markdown 模式中的源码在再次发生即时编辑前保持用户写法。标题独立保存，不自动注入正文 H1。
- 最近删除笔记保留 30 天；笔记本删除只将其笔记设为未分类。
- AI 生成文章未明确指定笔记本时归入“未分类”，同时出现在“全部笔记”；加入知识库只创建 `.note` 引用，不改变笔记本归属。
- 后台任务最多同时运行两个；同一对话或同一目标笔记的任务串行执行。应用重启后遗留的运行中、待审批和待回答任务标记为“已中断”，只能手动重试。
- 任务中心只接收“总结为笔记”和笔记 AI；普通对话与 Tiny Agent 均在原对话中执行，不创建任务中心记录。
- “总结为笔记”使用点击时的对话快照，成功后直接创建笔记，不向原对话添加总结指令或正文；同一对话不能同时存在两个活动总结任务。
- 后台任务输入不得包含 API Key、Token、密码或 Secret；终态记录最长保留 30 天并自动清理，用户也可随时手动清理全部终态记录。清理记录不删除其生成的笔记、对话消息或提案。
- 知识库文件操作只接受知识库 ID 和相对路径，规范化后必须仍在根目录。
- 导入同名文件默认保留两份，用户可选择替换或跳过。
- Windows/macOS 安装包将 Tiny Note 注册为 `.md/.markdown` 的可选编辑器，不抢占系统默认应用。用户选择 Tiny Note 或设为默认后，系统打开请求把 UTF-8 Markdown（单文件不超过 10 MB）绑定为源文件并立即打开，不创建无关联副本。Tiny Note 的自动保存同步写回源文件；写入前必须校验打开/上次保存时的内容哈希，检测到其他程序修改时拒绝覆盖并提示重新打开。同一路径再次打开复用原笔记记录并以磁盘内容刷新。
- 可搜索笔记标题/正文纯文本、知识库目录名/文件名和 `.note` 标题，不做全文语义索引。
- FIM 默认关闭，开启前提示外部 API 请求和潜在费用。
- API Key 存入本地 SQLite；不进入任何前端 DTO，配置读取只返回 `apiKeyConfigured`。

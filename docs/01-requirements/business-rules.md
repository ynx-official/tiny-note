# 业务规则（Approved）

最后更新：2026-08-28

- 笔记自动保存防抖 800ms，退出或切换前强制刷新。
- Markdown 源码编辑防抖 150ms 生成 HTML/纯文本并刷新预览，随后进入 800ms 保存。空文档、`1. `、`> ` 等正常编辑中间态使用宽容预览，不得阻断源码原文保存；若预览确实无法更新，保留最后有效 HTML 并明确提示“源码已保存”。同一编辑器会话切换普通文章时保持模式、预览开关和分栏比例；外部 Markdown 打开时固定使用即时编辑。每篇文章的渲染正文滚动比例按文章 ID 保存在当前设备，切换文章、切换模式和关闭前刷新，不进入工作区备份。
- 即时编辑会把正文序列化为语义等价的规范化 Markdown；Markdown 模式中的源码在再次发生即时编辑前保持用户写法。标题独立保存，不自动注入正文 H1。
- 最近删除笔记保留 30 天。删除普通笔记本时，直接子笔记本提升到被删笔记本的上一级，直属笔记移入“未分类”，三步在单一事务完成；确认框必须显示直属笔记数和子笔记本数。“未分类”为根级系统笔记本，不可移动、重命名或删除。
- 笔记本支持多级嵌套；任何移动不得形成自身或后代循环。同级先显示子笔记本，再显示直属笔记；笔记按置顶优先、更新时间倒序排列。
- 标签与正文及笔记树解耦，只在独立标签工作区和笔记右键菜单中管理。一篇笔记可关联多个标签；删除标签只删除标签及关系，不删除笔记。“未添加标签”是查询条件，不持久化为标签。
- AI 生成文章未明确指定笔记本时归入“未分类”，同时出现在“全部笔记”；加入知识库只创建 `.note` 引用，不改变笔记本归属。
- 后台任务最多同时运行两个；同一对话或同一目标笔记的任务串行执行。应用重启后遗留的运行中、待审批和待回答任务标记为“已中断”，只能手动重试。
- 任务中心只接收“总结为笔记”和笔记 AI；普通对话与 Tiny Agent 均在原对话中执行，不创建任务中心记录。
- “总结为笔记”使用点击时的对话快照，成功后直接创建笔记，不向原对话添加总结指令或正文；同一对话不能同时存在两个活动总结任务。
- 后台任务输入不得包含 API Key、Token、密码或 Secret；终态记录最长保留 30 天并自动清理，用户也可随时手动清理全部终态记录。清理记录不删除其生成的笔记、对话消息或提案。
- 知识库文件操作只接受知识库 ID 和相对路径，规范化后必须仍在根目录。
- 导入同名文件默认保留两份，用户可选择替换或跳过。
- Windows/macOS 安装包将 Tiny Note 注册为 `.md/.markdown` 的可选编辑器，不抢占系统默认应用。用户选择 Tiny Note 或设为默认后，系统打开请求把 UTF-8 Markdown（单文件不超过 10 MB）绑定为源文件并立即打开，不创建无关联副本。Tiny Note 的自动保存同步写回源文件；写入前必须校验打开/上次保存时的内容 MD5，检测到其他程序修改时拒绝覆盖并提示重新打开。同一路径再次打开先比较磁盘内容与已保存 MD5：未变化时直接复用 SQLite 缓存，变化时才从磁盘重新加载并刷新原笔记记录。
- “外部来源”展开区域的空白处右键提供“打开文件…”和“打开文件夹…”。打开文件支持多选 `.md/.markdown`；打开文件夹只做一次递归扫描，包含所有后代目录中的 Markdown，不跟随符号链接、不保存文件夹节点或建立监听。同一规范化路径复用既有外部记录；选择取消不提示，部分失败汇总提示，成功后展开外部来源并打开最后一个成功文件。
- 外部文件记录右键只提供“移除”。移除当前正在编辑的外部文件前必须先完成最新保存；保存冲突或失败时中止移除。移除只删除 Tiny Note 中的外部来源绑定及临时缓存，绝不删除或移动磁盘源文件；若移除当前项则切换到相邻外部项，无可用相邻项时回到全部笔记。
- UI 的显式搜索可查询笔记标题/正文纯文本以及知识库目录名/文件名；系统不建立全文索引，也不自动把搜索结果注入模型对话。
- Agent 的 `list_notes`、`search_notes` 和 `get_note` 是用户主动发起的笔记管理操作。普通列表与搜索排除最近删除和“外部来源”；空查询或仅含“笔记/note/notes”等集合泛词时返回最近更新列表，不能据此断言用户没有笔记。
- Agent 修改笔记前必须用精确 ID 读取完整 `contentMarkdown`；创建标题最多 50 个字符且不得把整篇正文作为标题；删除前必须确认精确 ID。
- Agent 笔记本写操作不得修改、移动或删除“未分类”，移动不得形成自身/后代循环。删除普通笔记本时，直属笔记归入“未分类”，直接子笔记本提升到被删节点的父级，不递归删除任何内容。
- FIM 默认关闭，开启前提示外部 API 请求和潜在费用。
- API Key 存入本地 SQLite；不进入任何前端 DTO，配置读取只返回 `apiKeyConfigured`。

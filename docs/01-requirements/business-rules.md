# 业务规则（Approved）

最后更新：2026-08-21

- 笔记自动保存防抖 800ms，退出或切换前强制刷新。
- Markdown 源码编辑防抖 150ms 生成 HTML/纯文本并刷新预览；只有三种表示均有效时才进入 800ms 保存。同一编辑器会话切换文章时保持模式、预览开关和分栏比例，不因单纯查看更新时间。
- 即时编辑会把正文序列化为语义等价的规范化 Markdown；Markdown 模式中的源码在再次发生即时编辑前保持用户写法。标题独立保存，不自动注入正文 H1。
- 最近删除笔记保留 30 天；笔记本删除只将其笔记设为未分类。
- 知识库文件操作只接受知识库 ID 和相对路径，规范化后必须仍在根目录。
- 导入同名文件默认保留两份，用户可选择替换或跳过。
- 可搜索笔记标题/正文纯文本、知识库目录名/文件名和 `.note` 标题，不做全文语义索引。
- FIM 默认关闭，开启前提示外部 API 请求和潜在费用。
- API Key 存入本地 SQLite；不进入任何前端 DTO，配置读取只返回 `apiKeyConfigured`。

# MVP 验收标准（Approved）

最后更新：2026-08-26

- Given 首次启动，When 创建笔记并输入内容，Then 800ms 内重启后可恢复标题和正文。
- Given 笔记已删除，When 在最近删除选择恢复，Then 笔记回到原笔记本；超过 30 天的记录不再显示。
- Given 知识库根目录，When 请求 `../` 或符号链接越界路径，Then Rust 返回稳定错误码。
- Given 同名导入，When 未指定替换，Then 原文件保留且新文件使用冲突后缀。
- Given 已安装 Windows 或 macOS 版本，When 用户从 `.md/.markdown` 的打开方式选择 Tiny Note 或将其设为默认后双击文件，Then 应用被唤起并直接打开绑定源文件；应用已运行时复用现有实例，编辑后自动保存回原文件而不创建无关联副本。
- Given 用户从系统打开 Markdown，When 编辑器显示该文件，Then 默认进入 Markdown 源码模式并显示“外部文件”提示、源文件名、“不会出现在笔记列表”说明和“导入到笔记”按钮；该文件只出现在独立的“外部来源”历史中，不出现在普通笔记树、普通搜索、标签、双向链接或工作区备份。
- Given 外部文件提示正在显示，When 用户点击关闭按钮，Then 当前文章的提示立即隐藏，并在重新打开该文章或重启应用后保持隐藏；其他外部文章的提示状态互不影响。
- Given 正在查看外部 Markdown，When 用户点击“导入到笔记”，Then 创建内容一致的普通本地笔记，路由、编辑器和笔记树立即切换到该副本；后续编辑副本不再写回外部源文件，原外部绑定保持独立。
- Given 外部来源中已有记录，When 用户点击记录，Then 比较磁盘内容 MD5 与上次保存值；MD5 相同时直接打开 SQLite 缓存，MD5 不同时重新加载磁盘正文并刷新缓存；When 点击分类行尾的清空按钮并确认，Then 只清除 Tiny Note 的外部打开历史，不删除任何源文件。
- Given 已绑定的 Markdown 被其他程序修改，When Tiny Note 尝试保存不同内容，Then 保存被拒绝、磁盘内容保持不变，并明确提示用户重新打开确认。
- Given HTML/Markdown 预览，When 内容含脚本，Then 预览 DOM 不执行脚本。
- Given FIM 未开启，When 光标停顿 2 秒，Then 不发起网络请求。
- Given 模型请求取消，When 点击停止，Then 前端收到 `cancelled` 且不插入半截结果。
- Given 数据库存在未删除普通笔记，When 用户询问“我有哪些笔记”或以空查询/“笔记”调用搜索，Then Agent 使用列表能力返回真实笔记及笔记本信息，不回答“没有任何笔记”，且外部来源与最近删除不出现。
- Given 存在标题或正文含 Storybook/中文主题词的笔记，When Agent 搜索相应关键词，Then 返回对应笔记并附笔记本元数据；When 首轮自然语言关键词无结果，Then 技能要求缩短关键词重试后才能报告未找到。
- Given Agent 要修改已有笔记，When 已确认精确 ID，Then 先读取完整 `contentMarkdown` 再生成提案，标题、列表、表格与其他格式不因只读纯文本而丢失。
- Given 用户通过 Agent 管理笔记本，When 创建、局部更新或移动普通笔记本，Then 层级和未提供字段保持正确；移动到自身/后代或修改“未分类”被拒绝。When 删除普通笔记本，Then 直属笔记移入“未分类”、子笔记本提升且无内容被递归删除。
- Given 用户没有在本轮手动选择引用，When 发起普通对话、笔记 AI 或 Agent 请求，Then 不读取或注入任何其他本地内容。Given 用户明确选择笔记或知识库文件，Then 只传入所选内容、保留来源事件并标记为不可信参考。
- Given 从旧版本升级且数据库含全文索引表与遗留工具策略，When 初始化数据库，Then 索引表、FTS 虚表、相关触发器和 `retrieve_knowledge` 策略被删除，笔记、提案、版本与聊天数据保持完整。
- Given 首次打开文章编辑器，When 未主动选择模式，Then 文章处于即时编辑；选择 Markdown 后切换文章仍保持 Markdown 和当前预览布局。
- Given 用户处于即时编辑或 Markdown，When 在 Windows/Linux 按 `Ctrl+/` 或在 macOS 按 `⌘+/`，Then 编辑器在两种模式间双向切换；正文或 CodeMirror 获得焦点时快捷键同样生效。
- Given 用户打开设置，When 进入独立“快捷键”分类，Then 快捷键按“编辑器”等功能分组展示；When 录入新的模式切换快捷键并重新加载应用，Then 当前设备继续使用该组合键且默认组合键不再切换模式；When 恢复默认值，Then `Ctrl+/`（macOS 为 `⌘+/`）重新生效。
- Given 使用即时编辑，When 输入 `# ` 等 Markdown 快捷语法或粘贴 Markdown，Then 内容立即以对应格式呈现；粘贴后可通过“查看源码”进入 Markdown。
- Given 进入 Markdown，When 修改源码，Then 150ms 后实时预览、HTML 和纯文本同步，并在 800ms 自动保存中原样保留源码换行；切回即时编辑后呈现同一内容。
- Given 正在 Markdown 源码中输入，When 内容短暂为空、只有 `1. ` 或只有 `> `，Then 不提示解析失败，源码仍按原文保存，后续继续输入时预览正常恢复。
- Given Markdown 包含连续的普通 `>` 引用元数据行，When 在即时编辑或 Markdown 实时预览中查看，Then 每个显式单换行都保持可见且原始草稿不被预处理改写；引用外普通段落以及引用内列表、代码块和表格仍遵循原有 Markdown 换行语义。
- Given 外部 Markdown 或待导入 Markdown 包含连续的普通 `>` 引用元数据行，When 用户从系统首次打开、从“外部来源”历史重新打开、导入为笔记或用模板创建笔记，Then 初次显示即应用相同的单换行规则，且保存的 Markdown 源码保持原文。
- Given Markdown 实时预览已打开，When 拖动分隔条或滚动任一栏，Then 比例始终处于 30%–70%，另一栏按滚动百分比联动；窄宽度使用上下布局；关闭预览后只显示源码。
- Given 源码包含脚本、事件属性、危险 URL 或非白名单样式，When 生成预览，Then 原始源码可保留，但持久化 HTML 不包含可执行内容。
- Given Markdown 包含合法的 `mermaid` 流程图或 `swimlane-beta` 泳道图，When 在即时编辑或 Markdown 预览查看，Then 显示图形而不是普通代码文本，围栏源码可无损继续编辑；When 导出 HTML/PDF，Then 从源码重新生成经清洗的矢量 SVG。
- Given Mermaid 图表较宽，When 首次渲染、源码变化或适宽状态下容器尺寸变化，Then 行内与大图视图默认重新适合当前宽度并给出完整概览，行内工具栏不显示重复的“适合宽度”按钮；When 用户主动缩放，Then 保留手动缩放状态，100% 保持 SVG 原始比例、图表保持矢量清晰且滚动只发生在图表舞台内；大图可在 10%–250% 间查看，按住鼠标左键可拖动画布，滚轮围绕鼠标指向的位置缩放；When 在大图工具栏选择“屏幕全屏”，Then 优先进入系统原生全屏，不支持时铺满应用窗口，Esc 先退出屏幕全屏、再次按下关闭大图并恢复焦点。
- Given Mermaid 语法错误、主题切换或源码快速连续变化，When 预览刷新，Then 旧异步结果不会覆盖新内容，错误块保留源码并允许重试，生成 SVG 不进入持久化 HTML。
- Given Mermaid 源码包含图片节点或外部资源，When 尝试预览，Then 在 Mermaid 渲染前拒绝该资源且不发起网络请求，源码仍完整保留并可继续编辑。
- Given 修改编辑器首个非空内容行，When 切换任一模式或等待自动保存，Then `notes.title` 按 Friday 规则同步更新；Markdown 源码保持用户输入的标题级别和换行。
- Given 光标位于即时编辑的专用标题节点，When 按 Enter、选择正文/H1–H3 或清除格式，Then Enter 进入普通正文段落，格式操作不把标题节点降级，派生标题最多保留 50 个字符。
- Given 进入 Markdown 模式，When 用户查看并操作格式工具栏，Then 工具栏保持可见，且粗体、斜体、删除线、行内代码、链接、标题、列表和引用操作直接修改当前源码选区。
- Given 用户查看文章工具栏，When 入口带有下拉菜单，Then “插入、文字颜色、背景颜色、标题、编辑模式、AI 指令”统一使用 Friday 式 12px 折线箭头；Given 用户在即时编辑或 Markdown 中打开标题下拉，When 查看格式选项，Then 按顺序显示“标题、标题 1、标题 2、标题 3、正文、小正”并以对应字号预览；When 点击文章正文或 Markdown 源码区域，Then 已打开的工具栏下拉立即关闭；When 对正文选择“小正”并切换模式，Then 小正文样式和内容保持不变。
- Given 用户在任一文章模式中打开“更多”，When 查看输出操作，Then “打印”“导出 PDF”和“导出 HTML”是三个独立入口，PDF 导出直接生成 `.pdf` 文件而不复用系统打印对话框。
- Given Markdown 草稿刚刚发生变化且尚未经过 150ms 解析防抖，When 用户立即打印或导出 HTML/PDF，Then 输出包含从最新草稿读取的标题和安全正文，标题不重复，且不包含应用外壳、工具栏或 AI 面板；HTML/PDF 中的 Mermaid 图表从围栏源码重新渲染，不复制编辑器瞬时 DOM。
- Given 单个 Mermaid 围栏无法渲染，When 导出 HTML/PDF，Then 导出继续，该位置显示渲染失败提示并保留完整源码。
- Given 导出的 HTML 包含一张或多张 Mermaid 图表，When 用户离线打开文件，Then 正文中的每张图都保持静态适宽，右上角依次显示较紧凑的“下载高清图”和“放大查看”；When 点击下载，Then 在本地把安全 SVG 转为白底四倍 PNG，并按最长边、总像素预算限制输出尺寸；When 点击放大，Then 进入独立聚焦层，工具栏只显示当前比例、适合宽度、全屏和关闭，不显示加、减或 100% 按钮；滚轮绕鼠标位置缩放，按住左键拖动画布，键盘也可操作；When 点击“进入全屏”，Then 图表面板通过 Fullscreen API 占满整个屏幕，缩放与拖动继续可用；When 处于系统全屏时按 Esc，Then 只退出全屏且聚焦层仍保留；When 再次按 Esc 或关闭，Then 聚焦层移除且焦点返回原按钮。When 打印该 HTML，Then 图表操作按钮隐藏且图形适合页宽。
- Given 导出 PDF，When 查看 Mermaid 图表，Then 只包含适合页宽的静态渲染结果，不包含 HTML 控件或脚本。
- Given 文章标题包含中文、Emoji、文件系统非法字符、保留名或为空，When 导出 HTML/PDF，Then 生成合法文件名；HTML 包含 UTF-8 声明和内嵌阅读样式，PDF 使用 A4 文章版式。
- Given PDF 正文很长或包含无 CORS 授权的远程图片，When 直接导出 PDF，Then 在浏览器画布安全范围内动态调整清晰度；超过范围时给出打印/拆分建议且不下载空白文件，无法嵌入的远程图片以可见占位说明替代而不静默消失。
- Given 尚未设置文件保存位置，When 用户导出 Markdown、HTML、PDF 或保存生成图片，Then 先选择文件夹并可勾选“以后都保存到此目录”；勾选后后续文件直接写入该目录，未勾选时仅本次使用。Given 文件保存成功，Then 显示“打开所在文件夹”“打开文件”“以后再说”三个操作并按此前后顺序排列。Given 设置页中的默认目录已更换或清除，Then 后续保存使用新目录或重新询问；同名文件使用递增后缀且不覆盖原文件。
- Given 桌面端导出文件已写入成功，When 结果弹窗出现，Then 用户可打开文件、在系统文件管理器中定位文件或选择以后再说；When 系统无法执行打开操作，Then 弹窗保留并显示错误，不误报已经打开。
- Given AI 提供全文替换，When 用户在任意模式应用替换，Then 三种内容表示同步且模式不变；非即时编辑模式的“应用插入”不可用。
- Given 对话或笔记 AI 正在生成，When 用户切换到其他 Tab 后再返回，Then 任务继续执行并从持久状态恢复进度和结果。
- Given 用户点击“总结为笔记”，When 后台任务成功，Then 只创建一篇基于点击时快照的笔记，原对话不新增总结问答消息。
- Given 应用在任务运行期间退出，When 再次启动，Then 任务显示为“已中断”且不会自动重复模型调用或写操作，用户可以手动重试。
- Given Agent 等待审批或结构化输入，When 用户仍在或重新打开原对话，Then 可以在对话时间线内处理请求并继续运行，任务中心中不出现该 Agent 对话。
- Given 任一后台任务已开始执行，When 用户查看任务中心，Then 运行中任务的执行时间逐秒更新，结束后保留该次尝试的最终耗时。
- Given 已存在模型服务，When 用户编辑连接名称、厂商、端点类型或 Base URL，Then 该连接下的模型共同使用更新后的连接信息，且空白 API Key 不覆盖已有凭据；原“其他”类型明确显示为“OpenAI 兼容服务”。
- Given 一个模型服务包含多个模型，When 用户查看模型设置，Then 界面只展示一个厂商连接卡片并在其下列出模型，不重复显示 Base URL 与凭据状态。
- Given 已存在带 Key 的模型配置，When 打开编辑页且不填写新 Key，Then 输入框保持空白并明确提示；获取模型列表和保存均由 Rust 使用原 Key，前端不会收到原 Key 明文。
- Given 模型选择 OpenAI Responses、OpenAI Chat 或 Anthropic，When 发起普通生成、Agent 或子 Agent 请求，Then Rust 使用对应的路径、认证头、请求体和流事件格式；旧配置继续使用 OpenAI Chat。

# 产品需求（首版）

状态：Approved
最后更新：2026-08-26

## 核心验收

1. 用户可以创建、编辑、搜索、导入、复制、移动、导出和恢复笔记。
2. 用户可以用多级笔记本树组织笔记，并在独立标签工作区批量关联和查找笔记；也可以管理个人/本地知识库，导入文件与网页并预览支持格式。
3. 用户可以配置 Friday 兼容的模型，并使用流式笔记 AI 操作及可关闭的 FIM。
4. API Key 写入本地 SQLite，不写入前端 localStorage 或日志。
5. 会话可以自动检索未删除笔记和文本类知识库文件，也可明确引用内容，并展示实际来源。
6. AI 对笔记的扩写、修改、替换和翻译先生成差异提案；用户确认后才应用，并可从持久版本恢复。
7. 文章编辑器提供 Notion 式即时编辑和带可选实时预览的 Markdown 源码编辑两个主模式，支持处理后 Markdown 与渲染内容双向同步；默认通过 `Ctrl+/`（macOS 为 `⌘+/`）切换模式，快捷键可在设置中自定义并仅保存在当前设备，具体行为以[文章编辑体验需求](editor-modes.md)为准。
8. 总结为笔记和笔记 AI 作为持久化后台任务执行；切换页面或最小化应用不影响执行，任务可在统一任务中心查看、取消或重试。普通对话与 Tiny Agent 保留当前页面内的即时流式体验，不进入任务中心；Agent 审批和结构化输入在原对话内处理。
9. 从 Windows“打开方式”或 macOS Finder 打开的 Markdown 默认进入源码编辑并明确标记为外部文件，只绑定并保存回原文件，不进入笔记树、搜索、标签、双向链接、知识库索引或工作区备份；用户点击“导入到笔记”后才创建一份独立的普通笔记副本。

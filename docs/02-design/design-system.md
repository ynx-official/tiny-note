# 视觉与交互（Approved）

最后更新：2026-09-21

使用 `awesome-design-md`（VoltAgent/awesome-design-md，Style ID `notion`）补充状态、焦点、响应式和无障碍规则；根据产品方确认，笔记/知识库页面直接迁移 Friday 的桌面壳、顶部标签栏、窄左轨、侧栏结构、编辑器工具栏、文件卡片、间距和明暗层级。Tiny Note 保留自己的品牌文字和图标；侧栏头像仅作静态视觉参考，不读取或迁移 Friday 用户数据。

主题支持 light/dark/system，中文/英文切换；主窗口默认 1280×800，最小 1024×700。

2026-09-21 根据产品方对笔记布局效果图的确认，对 Friday 基线做以下局部调整，以减少重复导航和工具栏换行：

- 左轨保留全部功能入口；顶部仅展示本次打开的工作区，Tiny Note 入口继续返回当前会话。笔记标签使用当前笔记标题，支持关闭和通过加号重新打开工作区。关闭标签不删除笔记或会话。
- 笔记侧栏默认 272px，可拖拽至 240–400px，并受窗口宽度约束；尺寸独立保存，不改变其他工作区侧栏。页头显示“笔记”、搜索、新建和更多选项；更多选项保留模板、导入、置顶筛选、创建笔记本与折叠侧栏。笔记本本身沿用既有名称排序。
- 目录主体展示“全部笔记”和笔记本树；最近删除与外部来源放在底部独立滚动区域。树行高 36px，当前笔记使用低饱和整行选中态。
- 编辑区与侧栏页头统一为 54px。常用编辑操作保持单行，列表及低频格式进入分组弹层；空间不足时将粗体、斜体、下划线和撤销/重做收进“更多格式”。保留文章模式、导出、目录和助理，目录不再悬浮于右侧。弹层支持 Escape 关闭与恢复触发按钮焦点。
- 文章展示真实笔记本路径。标题 28px，章节标题 20–22px，正文 15px/1.75；内容宽度上限 768px，标准左右内边距 56px，窄栏与 Markdown 分栏使用 24px。代码块使用浅色主题表面、等宽字体、语言选择和复制操作；沿用已有深色变量。
- 这些变化只调整展示和导航，不重新解释或转换已有正文。效果图中的示例文案、示例笔记和“已保存”不会写入真实数据或作为固定状态展示。

验证记录见[笔记工作区布局验证](../04-quality/note-workspace-layout.md)。以上是对原“固定功能页签”和平铺编辑工具栏约定的显式更新，其余 Friday 迁移边界不变。

2026-09-17 任务中心区分“等待执行 / 等待重试 / 重试延迟 / 失败”，直接展示重试次数、计划时间和上次错误；错误不再只藏于展开详情。页头提供“刷新状态”，自动刷新失败时保留旧列表并显示连接提示。生图页进度条同步实际任务状态。

2026-09-17 按用户要求调整图片输入：参考图生图、图片编辑、局部重绘的主入口统一为“选择本地图片”，已有历史记录时也不改变主入口。“从最近生成选择”作为独立的辅助入口。图片输入区域与提示词框支持 Ctrl/⌘+V 粘贴图片；普通文本保持默认粘贴行为。参考图最多 4 张；编辑及重绘可直接替换原图，替换成功后清空蒙版。沿用 PNG/JPEG/WebP、单张 20 MB、合计 50 MB 限制；读取失败保留原图，读取中切换模式丢弃旧结果。图片只在用户提交处理任务时发送服务端。

2026-09-15 经交互示意图确认：会话审批改为消息区内的紧凑确认区域，使用低饱和琥珀色边线，支持展开查看完整参数；成功确认后使用绿色状态行。顶部 Tiny Note 标签显示生成、待确认或待回答状态，并返回保留的当前会话。跨工作区切换保留草稿和阅读位置，1024px 窗口下标签缩小宽度以避开窗口按钮。实施边界与验证见[会话跨 Tab 连续性](../04-quality/chat-navigation-continuity.md)。

笔记侧栏采用 Friday 外壳内的紧凑单树：顶层“全部笔记”，文件夹行带折叠箭头，笔记作为直属叶节点；同级文件夹始终先于笔记。搜索只保留匹配笔记及祖先路径并自动展开，选中、悬停、键盘焦点和拖放目标均使用 Notion 式低饱和矩形状态。原“全部标签”筛选和列表标签芯片移除。

2026-09-21 按用户对“全部笔记”入口的要求，点击后在右侧展示跨笔记本的笔记摘要列表，包含未分类笔记，沿用服务端排序与分页。进入时清空搜索和置顶筛选，退出最近删除视图；已删除笔记和未导入的外部文件仍由各自入口管理。切换前保存当前编辑，保存失败保留原页面；列表显示标题、摘要、所属笔记本、更新时间，点击后打开正文。加载更多失败保留已有条目并支持重试。

功能轨在“知识库”下方固定增加“标签”，并提供顶部“标签”页签。标签工作区使用 250px 左侧标签列表与右侧关联笔记列表，显示标签计数、笔记本完整路径和更新时间；批量选择器使用细边框、紧凑行高和明确选中状态，不使用装饰卡片。

文章模式下拉沿用 Friday 工具栏密度，主模式为即时编辑和 Markdown，并按 Notion 规范使用 8px 矩形菜单、细边框、轻阴影、明确焦点和勾选状态。菜单以紧凑按键标签提示当前切换快捷键；设置导航提供独立“快捷键”分类，分类内按编辑器等功能分组，并使用可聚焦的组合键录入控件，清楚区分待录入、已保存、错误和恢复默认状态。默认显示 `Ctrl+/`，macOS 显示 `⌘+/`；自定义值仅保存在当前设备。Markdown 工具栏提供独立预览开关；分栏分隔条保持低干扰，但 hover 与拖动状态可辨识。CodeMirror 与预览共享当前明暗主题变量。Markdown 粘贴提示采用紧凑状态条，提供直接“查看源码”动作，不遮挡正文操作。

Mermaid 流程图和泳道图沿用代码块外壳，但图表舞台使用正文表面、细边框和紧凑矩形控制，不新增营销式渐变或装饰卡片。行内与全屏视图默认适合当前宽度，首次渲染、源码变化和适宽状态下的容器变化都会重新计算概览比例；用户主动缩放后保留手动状态。行内工具栏仅保留缩放和打开大图等高频动作，不显示重复的适宽按钮；大图工具栏保留适宽，并增加可切换的屏幕全屏按钮。屏幕全屏去掉弹层外边距、圆角和阴影，让画布占满可用视口；按钮保持 8px 以内的紧凑矩形、明确焦点与按下状态。全屏舞台使用抓手/抓取光标和一行低干扰操作提示，支持左键拖动画布及滚轮指向缩放。语法错误使用低饱和语义红和明确恢复入口。SVG 随亮暗主题重新渲染，不使用反色滤镜。

# 视觉与交互（Approved）

最后更新：2026-08-25

使用 `awesome-design-md`（VoltAgent/awesome-design-md，Style ID `notion`）补充状态、焦点、响应式和无障碍规则；根据产品方确认，笔记/知识库页面直接迁移 Friday 的桌面壳、顶部标签栏、窄左轨、侧栏结构、编辑器工具栏、文件卡片、间距和明暗层级。Tiny Note 保留自己的品牌文字和图标；侧栏头像仅作静态视觉参考，不读取或迁移 Friday 用户数据。

主题支持 light/dark/system，中文/英文切换；主窗口默认 1280×800，最小 1024×700。

文章模式下拉沿用 Friday 工具栏密度，主模式为即时编辑、Markdown、阅读，并按 Notion 规范使用 8px 矩形菜单、细边框、轻阴影、明确焦点和勾选状态。Markdown 工具栏提供独立预览开关；分栏分隔条保持低干扰，但 hover 与拖动状态可辨识。CodeMirror 与预览共享当前明暗主题变量。Markdown 粘贴提示采用紧凑状态条，提供直接“查看源码”动作，不遮挡正文操作。

Mermaid 流程图和泳道图沿用代码块外壳，但图表舞台使用正文表面、细边框和紧凑矩形控制，不新增营销式渐变或装饰卡片。行内与全屏视图默认适合当前宽度，首次渲染、源码变化和适宽状态下的容器变化都会重新计算概览比例；用户主动缩放后保留手动状态。图表块内部提供缩放、适宽和全屏，窄容器隐藏次要文字标签但保留可访问名称；全屏舞台使用抓手/抓取光标和一行低干扰操作提示，支持左键拖动画布及滚轮指向缩放。语法错误使用低饱和语义红和明确恢复入口。SVG 随亮暗主题重新渲染，不使用反色滤镜。

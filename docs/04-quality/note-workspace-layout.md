# 笔记工作区布局验证

状态：Review  
最后更新：2026-09-21  
关联：[设计系统](../02-design/design-system.md)、[文章编辑模式](../01-requirements/editor-modes.md)

## 验收范围

- 顶部工作区标签可以打开、切换与关闭；笔记标签显示实际文章名，关闭后数据仍然存在。Tiny Note 会话切换保留既有草稿、阅读位置与任务状态。
- 笔记目录保留搜索、新建、模板、导入、置顶筛选、树展开、回收站和外部来源，辅助入口固定在底部区域。
- 目录按钮位于工具栏右侧，正确反馈打开状态；更多格式保留编辑能力，支持 Escape 关闭与焦点恢复。
- 1280px 与 1024px 窗口的编辑工具栏保持单行；打开助理时低频操作进入更多菜单，弹层不被编辑区边界裁切。
- 正文、代码块与 Markdown 预览共享排版和主题；只改变显示，不改写笔记内容。

## 验证证据

2026-09-21 使用本机 Vite 的 test 模式挂载实际 AppShell、NotesView、NoteEditor 组件，以独立浏览器端示例数据检查界面，没有连接生产服务。

- 浏览器检查：1280px / 1024px、助理展开、更多格式弹层、深色主题、Markdown 分栏、顶部工作区菜单；检查中修复了窄编辑区弹层左侧裁切。
- 前端全量单元测试通过：101 个文件、452 项测试。
- 收尾新增菜单互斥测试后，重跑编辑模式、布局、侧栏、标签与会话连续性相关测试：5 个文件、37 项通过。
- lint、typecheck、check:contracts、check:components、check:styles、build（含启动资源预算）通过。
- 本次没有修改 Rust 薄壳；未运行原生安装包构建。桌面原生窗口行为仍需在 Tauri 中验收。

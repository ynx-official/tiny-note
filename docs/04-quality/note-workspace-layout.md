# 笔记工作区布局验证

状态：Review  
最后更新：2026-09-30
关联：[设计系统](../02-design/design-system.md)、[文章编辑模式](../01-requirements/editor-modes.md)

## 验收范围

- 顶部工作区标签可以打开、切换与关闭；笔记标签显示实际文章名，关闭后数据仍然存在。Tiny Note 会话切换保留既有草稿、阅读位置与任务状态。
- 笔记目录保留搜索、新建、模板、导入、置顶筛选、树展开、回收站和外部来源，辅助入口固定在底部区域。
- 目录按钮位于工具栏右侧，正确反馈打开状态；更多格式保留编辑能力，支持 Escape 关闭与焦点恢复。
- 1280px 与 1024px 窗口的编辑区头部保持两行：第一行笔记名称、保存状态、编辑模式与右侧操作，第二行格式工具；打开助理时低频操作进入更多菜单。
- 正文、代码块与 Markdown 预览共享排版和主题；只改变显示，不改写笔记内容。

## 验证证据

### 独立标题与两行工具栏（2026-09-30）

按产品方确认的效果图调整头部布局。即时编辑和 Markdown 共用独立名称输入框，修改正文或切换模式不再从正文自动提取名称；空名称回退为“无标题”，外部文件名称保持只读。

- 先添加头部回归测试并确认 5 项失败，再实现调整；收尾相关 11 个测试文件、98 项测试通过，覆盖改名保存、空名称、输入法组合输入、模式与笔记切换、失败重试、正文标题保留及导出。
- lint、typecheck、check:contracts、check:components、check:styles、build（含启动资源预算）通过。
- 浏览器以 Vite test 模式挂载实际 NotesView、NotesSidebar、NoteEditor，使用独立本地示例数据；外围窗口栏为预览容器，没有连接生产后端。
- 检查 1280px / 1024px、助理展开、Markdown 预览及深色主题；修复助理展开时旧样式导致右侧按钮组撑满并挤压标题输入框的问题。
- 未修改 Rust，未重新构建或验证 Tauri 安装包。本节取代下方历史记录中的单行工具栏要求。

### 模式切换等待保存的回归（2026-09-30）

- 复现普通笔记切换前等待保存请求：请求延迟时界面停留在 Markdown，请求拒绝时抛出未处理异常；菜单与快捷键两项新增回归测试均先失败。
- 修复后先提交内存草稿并切换模式，再异步保存，保存失败保留状态及重试入口。7 个相关测试文件、45 项通过；lint、typecheck、diff 空白检查通过。
- 浏览器使用本地测试容器模拟保存延迟与失败，确认保存中已进入即时编辑、失败后正文仍在、点击重试可恢复“已保存”。该证据不代表已复现用户真实后端错误；共享源码保护分支保持原有行为。

### 共享源码标记误拦截（2026-09-30）

- 进一步根据“部分文章不能切换”复现共享源码标记的无条件拦截，以及富文本更新被忽略；3 项组件回归先失败，修复后通过。
- 改为按已识别的扩展语法判断，普通源码文章可切换和保存。打开与切换不改写源码，过期 HTML 不再覆盖当前源码视图；保留无法转换内容并持续展示原因。
- 9 个相关测试文件、82 项通过，覆盖共享内容、原文保留、富文本保存、代码示例、扩展语法、保存失败及标题独立性。浏览器用本地示例验证普通共享文章切换成功、含公式文章显示具体说明；未访问真实业务数据。
- lint、typecheck、check:components、check:styles、build 及启动资源预算检查通过；未重新打包桌面安装包。

- 先补回归测试并确认 4 项失败，再实现修复：跨笔记本列表与分页重试、筛选清理与返回恢复、保存失败阻止切换、旧正文请求不覆盖列表。
- 全量前端测试 102 个文件、457 项通过；收尾调整后重跑相关 12 项通过。lint、typecheck、contracts、components、styles、build 与资源预算检查通过。

- 未连接真实业务后端，未修改 Rust；本记录不代表原生安装包或生产环境验收。

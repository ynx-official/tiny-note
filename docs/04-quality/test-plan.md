# 测试计划（Draft）

最后更新：2026-08-26

- Rust：旧库自动增加两处 `content_markdown`、三表示行映射、CRUD/复制、AI 应用、版本创建与恢复、软删除清理、笔记本删除、路径穿越/符号链接、导入冲突、SSE 事件和取消。
- Rust：`tags_json` 到 `tags/note_tags` 的去重迁移、空归属到“未分类”、扁平笔记本到 `parent_id`、多级移动与循环拒绝、中间节点删除事务、标签增删改/批量关联/级联清理、备份 v3 往返和 v1/v2 兼容；另覆盖置顶、模板和 `[[双向链接]]` 同步、Base64 二进制导入、URL 导入限制、单文件增量索引及重命名/删除后的旧索引清理。
- Markdown：GFM、代码语言、图片、任务列表、普通/复杂表格、下划线、高亮、颜色、彩色高亮、对齐、上下标和混合 HTML 往返；连续普通引用行保留单换行，同时断言引用外正文及引用内列表、代码块、表格不受影响；脚本、事件属性、危险 URL/Data URL 和非白名单样式清洗。
- Mermaid：流程图与原生 `swimlane-beta` 围栏往返、渲染前外部资源拦截、严格安全配置与泳道标题兼容的 SVG 二次清洗、内部主题样式与 `url(#fragment)` 保留、节点/分组不回落为默认黑色、解析错误、竞态丢弃、亮暗主题、原始比例、首次渲染与源码变化默认适宽、适宽状态下容器变化自动重算、手动缩放退出自动适宽、行内不显示重复适宽按钮、行内 75%–250% 手动缩放、大图 10%–250% 独立缩放、原生屏幕全屏与应用窗口铺满回退、两级 Esc 退出、左键 Pointer Capture 拖动画布、滚轮鼠标锚点缩放、四向滚动边界、复制源码及非持久化 SVG。
- Vue：即时编辑与 Markdown 两种主模式的默认值和菜单顺序、模式跨文章保持、Markdown 预览开关、键盘导航、两种模式下格式栏可见与源码选区操作、标题下拉六项顺序与字号层级、“小正”块应用/取消及 Markdown 往返、即时 Markdown 输入规则、粘贴后查看源码、CodeMirror 150ms 解析与 800ms 保存、空白/空列表/空引用等编辑中间态容错、双向切换、Friday 式专用标题节点、50 字符派生上限、标题 Enter 与格式保护、旧笔记延迟回填、AI 全文同步和 Markdown 插入限制；覆盖 Windows/Linux `Ctrl+/`、macOS `⌘+/`、正文与 CodeMirror 焦点下切换、自定义组合键、旧键失效、设备本地持久化和恢复默认值。
- 文章输出：打印、PDF、HTML 三个独立入口；150ms 防抖前的最新草稿同步；首行标题只输出一次、空正文、中文/Emoji/非法文件名与 255 字节上限；HTML UTF-8、自包含样式、当前语言和二次清洗；PDF 文件头、A4 多页、分页、中文、代码块、任务列表、表格、链接和图片，以及长文画布倍率保护、超限错误、在生产 CSP 下通过 `img-src` 完成远图匿名 CORS 嵌入、失败/超时/数量与内存预算占位；首次目录选择、记住/不记住、取消、设置页更换/清除、浏览器回退、同名避让、路径穿越拒绝与 64 MiB 上限；导出成功三选项、默认焦点、Escape、打开失败反馈及非导出路径拒绝；打印只显示文章并等待异步原生命令；完成后释放 Blob URL 与临时渲染 DOM；Mermaid 持久化仍只保留源码，HTML/PDF 导出时重新渲染并嵌入清洗后 SVG，覆盖流程图、泳道图与失败保留源码；HTML 正文只保留静态图与“放大查看”，聚焦层与应用内预览共用视口内核，覆盖自然尺寸、适宽下限、工具栏去除加/减/100% 按钮、15% 滚轮步进及 32ms 节流、鼠标锚点、滚动边界、Pointer Capture 左键拖动、键盘、响应式重算、焦点陷阱、Fullscreen API 进入/退出与失败回退、Esc 分层退出与焦点恢复、离线运行及打印隐藏按钮，PDF 断言不注入交互运行时。
- Markdown 预览：横竖布局、30%–70% 拖动边界、双向百分比滚动及来源锁防循环。
- 浏览器：1280×800 与 1024×700、亮/暗主题、深层笔记本树、长名称、搜索祖先展开、键盘导航、笔记/笔记本拖放、空标签和大量标签；确认编辑器、笔记树和笔记页不存在标签输入、标签芯片或“全部标签”筛选。另验证模式菜单只有即时编辑与 Markdown、快捷键提示、默认与自定义组合键录入/切换/恢复；用多泳道和宽图检查溢出、舞台滚动、全屏左键拖动、鼠标位置锚定缩放、焦点和可读性；在 Windows WebView2、macOS WKWebView 和 Linux WebKitGTK 抽样验证 HTML/PDF 下载与系统打印预览。
- E2E：首次启动、重启恢复、导入预览、删除恢复、模型配置和拖放。
- 系统文件打开：Rust 覆盖 `.md/.markdown` 参数筛选、队列去重、单次路径授权、UTF-8 BOM、源文件写回、外部修改冲突拒绝，以及外部记录不进入笔记/标签列表、搜索、双向链接和备份；Vue 覆盖外部标记、默认源码模式、列表隔离、显式导入副本、路由跳转和读取失败提示；Windows 验证 NSIS 注册与运行中实例转发，macOS 在原生 runner 验证 Finder 打开事件和 DMG 安装后的“打开方式”。
- 模型端点：旧库默认迁移到 OpenAI Chat；Vue 覆盖端点选择、编辑回填和保存；Rust 覆盖三种路径、认证、文本/工具请求体、SSE 文本与工具增量、用量归一化和非流式响应解析。
- 后台任务：数据库迁移与重启中断、敏感字段拒绝、重复总结防护、状态转换、重试关联、同资源串行和跨资源最多两个并行；Vue 覆盖应用级 Channel、任务角标与筛选、取消/重试、总结快照不污染原对话，并验证普通对话与 Tiny Agent 均不会进入任务中心。Agent 审批、结构化输入和恢复由对话页单独覆盖。

在 Windows 开发机运行 `npm run test:unit`、`npm run lint`、`npm run build`、`cargo fmt --check`、`cargo test`、`cargo clippy --all-targets --all-features -- -D warnings` 和 `npm run tauri:build`；Windows、Linux、macOS 双架构安装包需 CI runner 证据，在线升级还需从上一正式版本完成一次真实检查、下载、安装和重启验收。
